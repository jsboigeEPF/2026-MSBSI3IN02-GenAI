# Bachelor BSI3 · Intelligence artificielle générative

**Pour commencer :** ouvrez le [cours Moodle](https://moodle.epf.fr/course/view.php?id=15233), puis le [catalogue](docs/CATALOGUE.md). Comparez deux fiches : quel résultat permettrait de départager votre prototype d’une solution simple ? Faites confirmer votre sujet en séance avant de développer. Ne publiez pas de liste nominative dans une issue.

- **Catalogue** : [87 fiches en douze familles](docs/CATALOGUE.md), chacune avec son verrou technique, son protocole de réussite, son plan B, ses notebooks CoursIA et ses références. Les fiches « hybride CoursIA » partent d’un notebook d’une autre série du dépôt (contraintes, probabilités, théorie des jeux, IA symbolique, compression, finance, apprentissage par renforcement) et y ajoutent un modèle génératif : le modèle propose, un calcul indépendant vérifie.
- **Support principal** : [chapitre VIII – IA générative, PDF de projection](support/chapitre-viii-genai.pdf). Retrouvez les [neuf chapitres de la série généraliste IA 101](https://github.com/jsboige/CoursIA/tree/main/slides#inventaire-des-decks). [Atlas](support/atelier-atlas.pdf) est une activité complémentaire sur les preuves et l’abstention, pas le cours complet.
- **Activités en séance** : Mind-Meld pour formuler une hypothèse sur les embeddings, polysémie pour discuter du contexte, variation d’un seul paramètre de diffusion, puis Atlas après la recherche hybride. Une activité collective n’est pas un rendu de TP.
- **TP : exercices des notebooks GenAI.** Trois points d’entrée : [02_PromptEngineering](https://github.com/jsboige/CoursIA/blob/main/MyIA.AI.Notebooks/GenAI/Texte/02_PromptEngineering.ipynb) (ex. 2 : comparer few-shot et zero-shot sur un jeu étiqueté) ; [03_Structured_Outputs](https://github.com/jsboige/CoursIA/blob/main/MyIA.AI.Notebooks/GenAI/Texte/03_Structured_Outputs.ipynb) (ex. 1 : valeur absente ou inventée) ; [01-Hands-On-Grounding](https://github.com/jsboige/CoursIA/blob/main/MyIA.AI.Notebooks/GenAI/RAG-et-Memoire-Semantique/01-Hands-On-Grounding.ipynb) (ex. 2bis : exclure une source ; ex. 3bis : mesurer indexation et stockage). Vérifiez la disponibilité de l’exercice en séance ; la correction se propose par PR dans CoursIA et non dans ce dépôt.
- **Projet** : forkez ce dépôt, copiez [le gabarit](template-groupe/README.md) dans `groupe-<nom-court>/` et ouvrez une PR vers ce dépôt. Ne modifiez pas les dossiers voisins. Pour demander de l’aide, précisez les étapes tentées, le résultat attendu et le symptôme, sans clé ni donnée personnelle.
- **Soutenance** : montrez une comparaison sur des cas non utilisés pour la mise au point, un échec expliqué et une démonstration de secours. Les horaires publiés sont sur Moodle.
