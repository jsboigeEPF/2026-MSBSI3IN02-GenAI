# Bachelor BSI3 · Intelligence artificielle générative

**Pour commencer :** ouvrez le [cours Moodle](https://moodle.epf.fr/course/view.php?id=15233), puis le [catalogue](docs/CATALOGUE.md). Comparez deux fiches : quel résultat permettrait de départager votre prototype d’une solution simple ? Faites confirmer votre sujet en séance avant de développer. Ne publiez pas de liste nominative dans une issue.

- [PDF à projeter](support/atelier-atlas.pdf) · [Source Slidev : de la réponse plausible à la réponse vérifiable](support/slides.md) · [chapitre VIII complet de CoursIA](https://github.com/jsboige/CoursIA/tree/main/slides/08-ia-generative).
- **TP** : travaillez sur un exercice ouvert de [CoursIA](https://github.com/jsboige/CoursIA), vérifiez sa disponibilité en séance et proposez la correction par PR dans CoursIA. Ce dépôt Bachelor accueille les projets, pas les corrections de TP.
- **Projet** : forkez ce dépôt, copiez [le gabarit](template-groupe/README.md) dans `groupe-<nom-court>/` et ouvrez une PR vers ce dépôt. Ne modifiez pas les dossiers voisins. Pour demander de l’aide, précisez les étapes tentées, le résultat attendu et le symptôme, sans clé ni donnée personnelle.
- **Soutenance** : montrez une comparaison sur des cas non utilisés pour la mise au point, un échec expliqué et une démonstration de secours. Les horaires publiés sont sur Moodle.
